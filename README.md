# CWS勤怠自動化ツール セットアップ手順

> 識別ID: `CWS勤怠自動化ツール_v2.3`（問い合わせ・バージョン確認の際はこの文字列をお伝えください）

> **管理者の方へ**: 管理画面連携（稼働状況・利用期限・バージョン確認・利用統計等）の詳細は [ADMIN.md](extension/ADMIN.md) を参照してください。

## 0. ファイルの入手

配布された ZIP ファイル(`kintai-helper-extension.zip` など)を、PC内の好きな場所に展開(解凍)してください。展開後にできるフォルダの中の **`extension`フォルダ**(`content.js` や `manifest.json` が入っているフォルダ)を、以降の手順で使用します。

> 展開したフォルダは今後も拡張機能の実体として使われ続けるため、デスクトップなど分かりやすい場所に置き、削除・移動しないようにしてください。

この拡張機能はEdge・Chromeのどちらでも同じように使えます（Chromiumベースのブラウザ共通の仕組みのみを使用しているため）。以下の手順ではEdgeの場合とChromeの場合のアドレスを併記していますので、お使いのブラウザに合わせて読み替えてください。

## 1. ブラウザのセキュリティ設定（HTTPサイトの警告を回避）

対象サイトが `http://` （非HTTPS） のため、フォーム送信時に「送信しようとしている情報はセキュリティで保護されていません」という警告が出ることがあります。以下の設定で回避できます。

1. アドレスバーに以下を入力してEnter
   - Edgeの場合: `edge://flags/#unsafely-treat-insecure-origin-as-secure`
   - Chromeの場合: `chrome://flags/#unsafely-treat-insecure-origin-as-secure`
2. 表示された「Insecure origins treated as secure」の入力欄に以下を入力
   ```
   http://jinkyuwap.fsi.local
   ```
3. 右側のドロップダウンを「無効」から「**有効**」に変更
4. 画面下部に表示される「再起動」ボタンをクリックしてブラウザを再起動

> この設定は`edge://flags`（Chromeの場合は`chrome://flags`）という実験的機能の画面のため、ブラウザの大型アップデート時にリセットされることがあります。警告が再発した場合はこの設定を確認してください。

## 2. 拡張機能のインストール

1. アドレスバーに以下を入力してEnter
   - Edgeの場合: `edge://extensions/`
   - Chromeの場合: `chrome://extensions/`
2. 左下（Chromeの場合は右上）の「開発者モード」のトグルをON
3. 「展開して読み込み」（Load unpacked）ボタンをクリック
4. フォルダ選択ダイアログで、「0. ファイルの入手」で選んだ`extension`フォルダ(`content.js` や `manifest.json` が入っているフォルダ)を選択
5. 拡張機能の一覧に「CWS勤怠自動化ツール」が追加されていれば完了

拡張機能はツールバーアイコンやポップアップを持たず、CWSの勤怠入力画面（`http://jinkyuwap.fsi.local/cws/*`）に自動的に機能を埋め込む形で動作します。

> **注意**: CWSは1つのログインセッションにつき「今どの画面にいるか」を1つだけ追跡する作りのため、自動処理（3-1, 3-3, 3-4, 3-5）の実行中に同じブラウザで別のCWSタブを開いたり操作したりすると、セッションの画面追跡が食い違い、処理中に想定外にメインメニューへ戻されることがあります。その場合は自動で月一覧への復帰を試みますが（3-8参照）、なるべく自動処理が終わるまでは他のCWSタブでの操作は控えてください。

## 3. 使い方

### 3-0. 客観差異理由CDの選択式入力

日次入力画面の「客観差異理由CD」欄(本来は番号を直接打ち込む自由入力欄)を、意味が分かる選択式(プルダウン)に自動で置き換えます。選択した値がそのまま元の欄に反映されるため、番号を覚えておく必要はありません。

### 3-1. 他日へ一括入力する

1. CWSにログインし、勤怠実績の**日次入力画面**を開く（この日の内容が他日にコピーされる元になります）
2. 日付見出しの下に表示される「他日へ一括入力する」チェックボックスをONにする
3. カレンダー（日曜始まり7列、未入力=白 / エラーあり=赤 / 入力済み=緑 / 休暇=青、土日祝は赤字）が表示されるので、同じ内容を反映したい日をクリックして選択する（複数選択可）。以下のボタンでまとめて選択・解除もできる
   - 「全選択（平日）」: 土日・祝日（会社独自の休日ラベル含む）以外の平日を全て選択
   - 「全選択（勤務日）」: 土日・祝日・休暇を除いた実際の勤務日のみを全て選択
   - 「全選択（エラー日）」: エラー（赤背景）表示の日を全て選択
   - 「全選択解除」: 選択をまとめて解除
4. カレンダーの下の「コピーする項目」で、他日にコピーしたい項目だけチェックを入れる（初期状態は前回設定を引き継ぎます）。「全選択」「全選択解除」で一括切り替えも可能
   - 勤怠 実績 / 在宅勤務・終日外出実績 / 工数 実績 / フレ有休などの30分単位休暇 / 休憩補正 / 私用外出・リフレッシュタイム・午後出社時の休憩 / 私有車利用実績 / 報告欄
5. この日（表示中の日）の入力はそのまま通常通り行い、**「次へ」→確認画面→「申請」**まで自分の手で進める
   - 「申請」を実際に押した場合のみ、選択した他日への自動反映が始まります
   - 「月一覧へ」などで申請せずに一覧画面へ戻った場合は、他日へのコピーは行われません
6. 「申請」後に月一覧画面に戻ると、画面中央に「他日へ反映中」というオーバーレイが表示され、選択した他日の詳細画面を自動で開いて入力・「次へ」・「申請」まで自動的に進みます
   - 処理中は「処理を中断する」ボタンでいつでも中断できます
   - 入力内容の検証エラー等で「次へ」を押しても確認画面に進めない日があっても、全体は中断せずその日だけスキップして次の日へ進みます。スキップした日があった場合は、完了時に対象日と理由の一覧が表示されます（自動では閉じません）
   - 反映が完了すると「反映が完了しました」の表示に切り替わり、数秒後に自動で消えます（スキップした日がなければ）

### 3-2. 確認画面での確認

「次へ」を押して確認画面に進むと、他日へ一括入力が有効な場合はここにも一覧が表示され、以下を（変更はできませんが）確認できます。

- 反映先として選択した日（カレンダー上でハイライト）
- 実際にコピーされる項目一覧（✅=コピーする、✕=コピーしない）

### 3-3. 休暇の申請忘れチェック

月一覧画面を開くたび、表示中の月に「有給休暇」「他休」「特別休暇」などの休暇日があるのに「申請中」「確認済」になっていない（未申請の）日がないかを自動でチェックします。まだ開始していない未来の月（例: 今が9月なら10月以降）は、CWSが登録を受け付けず不具合の原因になるため対象外です。

- 未申請の休暇日が1件以上あると、画面中央に「⚠ 休暇の申請忘れにご注意」というポップアップが表示されます
- 「申請する」ボタンを押すと、対象の休暇日すべてについて、詳細画面を自動で開いて「次へ」→確認画面「申請」までを連続で自動処理します（休暇日は勤務区分が既に自動選択済みのため、追加の入力は行いません）
  - 処理中は「処理を中断する」ボタンでいつでも中断できます
- 「閉じる」ボタンでポップアップを閉じるだけで、何もせず一覧画面に戻ることもできます

### 3-4. 出勤日の未申請チェック（月初めの見込み入力向け）

月一覧画面を開くたび、表示中の月の出勤日（土日・祝日・休暇日を除く日）で「申請中」「確認済」になっていない（未申請の）日がないかを自動でチェックします。月初めにまとめて見込み入力・申請する運用を想定しているため、当月内でまだ迎えていない未来の日も対象になります。ただし、まだ開始していない未来の月（例: 今が9月なら10月以降）は、CWSが登録を受け付けずメインメニューに戻されてしまうため対象外です。

- 未申請の出勤日が1件以上あると、画面中央に「⚠ 出勤日の申請忘れにご注意」というポップアップが表示されます（休暇の申請忘れポップアップとは別に表示されます）
- 「申請する」ボタンを押すと、対象の出勤日すべてについて、詳細画面を自動で開いて「次へ」→確認画面「申請」までを連続で自動処理します（勤務区分は既に自動選択済みのため、追加の入力は行いません）
  - 処理中は「処理を中断する」ボタンでいつでも中断できます
- 「閉じる」ボタンでポップアップを閉じるだけで、何もせず一覧画面に戻ることもできます

### 3-5. 一括入力（PC客観データ等から実行時間・工数を自動算出して一括申請）

月一覧画面に「一括入力」ボタンが追加されます。押すとポップアップが開き、以下を設定できます。

- カレンダーで自動申請したい日を選択します（複数選択可）。
- 在宅/外出実績は「在宅勤務/終日外出実績」の区分です。
  - 「更新しない」: 元の値のまま変更しません。
  - 「在宅勤務なし」「終日外出」「終日在宅」: 在宅勤務時間帯を0:00に設定します。
  - 「一部在宅（通勤出社あり）」: 時間帯欄が未入力の場合、実行時間と入退館客観データの差分（重ならない部分）から10分単位で自動算出します。
  - 「一部在宅（通勤出社なし）」: 自動算出できないため、時間帯欄が未入力のまま登録しようとするとエラーになります。
  - 「自動判別」: 日ごとにPC客観データ・入退館客観データの有無と差分から、以下のルールで実施区分を自動選択します（在宅勤務時間帯の入力は不要です）
    - PC客観データ・入退館客観データがともに「なし」→ 在宅勤務なし
    - PC客観データのみ「あり」→ 終日在宅（通勤出社なし）
    - 両方「あり」で時間の差分が30分未満 → 在宅勤務なし
    - 両方「あり」で時間の差分が30分以上 → 一部在宅（通勤出社あり）（在宅勤務時間帯も自動算出）
- 登録番号ごとに使用時間を入力できます。空欄のままにすると、実働時間から他の登録番号の使用時間を差し引いた残りを、空欄の登録番号の数で10分単位に均等に割って自動入力します（端数は最後の1件にまとめます）。登録番号を1件も入力しなければ工数の登録は行わず、他の項目のみ設定します。
- 実行時間は、未入力の場合は月一覧のPC客観データ→（なければ）入退館客観データ→（どちらもなければ）9:00〜17:30の優先順位で決定し、10分単位で切り捨てて入力します。入力した場合（時:分、未入力は0として扱います）は選択した全ての日にその時間を使用します。開始・終了の日付(前日/当日/翌日)は時間入力欄の左のプルダウンで選択できます（初期値はどちらも「当日」）。終了日が開始日より過去になっている場合は「一括登録」実行時にエラーになります。
- 既にその日に登録済みの工数がある場合は、いったん全て削除してから入力し直します。
- 既に「申請中」の日を選んでも、内容を上書きして再度申請します。
- 指定済みの使用時間の合計が実働時間と一致しない場合も登録は試み、ログに警告を残した上でCWS側の判定に委ねます（CWSが受け付けない場合はこの日をスキップします）。
- 登録できずスキップした日があった場合は、完了時に対象日と理由（CWS画面に表示されたエラー文など）の一覧が表示されます（自動では閉じません）。詳細な処理ログにも同じ内容が記録されます。
- 処理中は「処理を中断する」ボタンでいつでも中断できます。
- まだ開始していない未来の月（例: 今が9月なら10月以降）はCWSが登録を受け付けないため使用できません。

### 3-6. 報告欄の記入漏れチェック

月一覧画面を開くたび、以下のいずれかに該当するのに報告欄にコメントが記載されていない日がないかを自動でチェックします。

- 実労働時間が13.5時間を超えている日（社内規定の「半徹」に該当）
- 客観差異理由CDに「40（その他）」が設定されている日

該当する日が1件以上あると、画面中央に「⚠ 報告欄の記入漏れにご注意」というポップアップが表示され、対象の日付が一覧表示されます（上記2つはそれぞれ別のポップアップで、色も異なります）。

- このチェックは自動申請などは行わず、注意喚起のみです。「閉じる」ボタンでポップアップを閉じ、該当日の詳細画面を開いて報告欄に手動でコメントを記入してください

### 3-7. 実行時間の乖離チェック

月一覧画面を開くたび、実行時間（開始・終了）がPC客観データと30分以上乖離している日がないかを自動でチェックします（PC客観データが「なし」の日は比較対象外。入退館客観データは外出・来客対応等で乖離しやすく誤検知の元になるため、この判定には使用しません）。

- 該当する日が1件以上あると、画面中央に「⚠ 実行時間の乖離にご注意」というポップアップが表示され、対象の日付が一覧表示されます
- このチェックも自動申請などは行わず、注意喚起のみです。「閉じる」ボタンでポップアップを閉じ、該当日の詳細画面を開いて実行時間を確認・修正してください
- 該当する日は、月一覧の表で「実行時間」列のセルが黄色になります。表の直前にある「日次実績状況＞申請中：[　]　確認済：[　]…」という凡例行の末尾にも、同じ「ラベル：[色見本]」の形式で「客観差異：[　]」が追加されます

### 3-8. エラー発生時のログ確認

自動処理（3-1, 3-3, 3-4, 3-5）の途中で想定外のエラーが発生し処理が中断した場合、通常の完了表示の代わりに「✗ エラーが発生しました」というパネルが表示されます。

- 他のCWSタブでの操作等により処理中にメインメニューへ戻された場合、まずは自動で「勤怠」→「勤怠実績　入力」の順にリンクをたどり月一覧への復帰・処理再開を試みます（最大5回まで。ログに「△ 想定外の画面(メインメニュー等)に遷移したため、月一覧への復帰を試みます」と表示されます）。復帰できた場合はこのパネルは表示されません
- 復帰を試みても直らない場合や、復帰リンクが見つからない場合にこのパネルが表示されます
- 入力内容は保持されているため、選択し直さずにそのまま再度実行できます
- 何度か試してもうまくいかない場合は、下記のログを添えて管理者へご連絡ください
- どんな操作・入力を試みた結果エラーになったのかが分かるよう、それまでの処理ログが全て表示されます
- 「ログをコピー」ボタンでログ全文をクリップボードにコピーできます
- 「テキストで保存」ボタンでログ全文を`.txt`ファイルとして保存できます
- このパネルは自動では閉じません。内容を確認・保存した上で「閉じる」ボタンを押してください
- 原因調査を依頼する場合は、コピーまたは保存したログをツール作成者に共有してください

### 3-9. ポップアップ表示のON/OFF設定

月一覧画面の右上に「ポップアップ設定」ボタンが表示されます。押すと、以下の注意喚起ポップアップの表示有無を個別にON/OFFできる設定画面が開きます(初期状態は全てON)。

- ⚠ 休暇の申請忘れにご注意(3-3)
- ⚠ 出勤日の申請忘れにご注意(3-4)
- ⚠ 報告欄の記入漏れにご注意(半徹)(3-6)
- ⚠ 報告欄の記入漏れにご注意(客観差異CD=40)(3-6)
- ⚠ 実行時間の乖離にご注意(3-7)

「保存」を押すとブラウザに設定が保存され、次回以降の月一覧画面表示にも引き継がれます。「閉じる」を押すと変更を保存せずに閉じます。OFFにしたポップアップは表示されなくなるだけで、対応するチェック自体(未申請日の判定など)は変わりません。

## 4. 更新方法

新しいZIPファイルを配布された場合は、以下の手順で入れ替えてください。

1. アドレスバーに以下を入力してEnter
   - Edgeの場合: `edge://extensions/`
   - Chromeの場合: `chrome://extensions/`
2. 「CWS勤怠自動化ツール」の拡張機能カードにある「削除」ボタンをクリックして削除する
3. 旧バージョンの拡張機能を削除する
4. 新しいZIPファイルをPC内の好きな場所に展開(解凍)する
5. 手順1の拡張機能の一覧画面で「開発者モード」がONになっていることを確認し、「展開して読み込み」（Load unpacked）ボタンをクリックして、手順4で展開した新しいフォルダを選択する
